# 同类游戏参考（2026-10 调研）

来源：Stockpile 规则与策略文章、Acquire 规则、M.U.L.E.（C64-Wiki / Wikipedia）、Offworld Trading Company 设计分析（gamedesignthinking）、Dope Wars 报道（Village Voice 2000）、Wall Street Kid 评测、增量游戏资料。

## 一、每个参考点能偷什么

| 游戏 | 它做了什么 | 对我们的启发 |
|---|---|---|
| **Stockpile**（桌游） | 每轮私发「公司卡+预测卡」配对＝内幕消息，另有 1 对公开信息；股价涨过 10 会拆股（股份翻倍），跌破 1 破产归 5 | 信息不对称本身就是玩法；传闻要分「确知/半信/噪音」；拆股和破产是有戏的结构事件 |
| **Acquire**（桌游） | 连锁合并时最大股东拿奖金，控股权=收益权 | 股份不只是价格敞口，事件里应该有「权利/赔付」：被并购按溢价强平、退市归零 |
| **M.U.L.E.**（1983） | 随机事件（陨石/太阳风暴）影响产量；玩家卖得多→价格跌（供给冲击）；还有纯随机捣乱的 Wampus | **玩家行为要能推动价格**（砸盘/扫货），否则"操盘"只是看盘 |
| **Offworld Trading Co.** | 13 种资源，资源既能卖也能变成产能（boosting engine），有正反馈环 | 缺一条「用钱买能力→赚更多钱」的循环：情报/止损/杠杆 |
| **Dope Wars**（1986） | 5 分钟一局、随机事件、幽默公告文案（"哥伦比亚货轮甩掉海岸警卫队！"） | 文本梗是「会心一笑」的主要来源，成本极低 |
| **Wall Street Kid**（NES） | 反例：跟着报纸提示买就赢，30 分钟就知道无聊 | 提示不能太准，否则变成执行任务 |
| **增量/放置游戏** | 长线靠跨局成长（解锁、图鉴、永久加成） | 图鉴奖励已经开了一个头，可扩成永久成长 |

## 二、按「价值/成本」排的候选

1. **市场新闻梗**（文字库 + 随机播报）— 成本极低，直接产出「会心一笑」
2. **大单冲击价格**（你的买卖推动盘口，越大越滑）— 把"看盘"变成"操盘"
3. **内幕消息三档**（确知 / 传闻 / 噪音，且可能过期骗人）— 复用现有传闻系统
4. **股份结构事件**（拆股翻倍 / 破产归零 / 被并购溢价）— 让"持有"有后果
5. **用钱买能力**（情报、止损单、杠杆）— 建立正反馈环
6. **跨局永久成长**（解锁标的、初始资金、图鉴加成）
